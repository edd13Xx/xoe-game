# XOE on a phone — plain-words guide

Updated Nov 11, 2026 (CST). Nothing here has been published, hosted, signed, or uploaded.
Paper / testnet only. No real money. The game never ships an xAI key; each player pastes their own.

There are three ways to play XOE: Unknown Orbital Engine on a phone.

## 1. The single file (works today, no hosting)

`Unknown-Orbital-Engine-XOE-v19-2026-11-10.html` is the whole game in one file.

- On iPhone, open it **in Safari** (Files app → the file → Share → **Open in Safari**).
- Quick Look, Files previews, and chat-app previews block JavaScript, so they show a blank page or the
  "Starting XOE…" hint. That is expected. It is not a bug in the game.
- Storage can be blocked when the file is opened like this. The game keeps going and keeps your
  progress in memory for that visit.

## 2. Install as a Home Screen app (PWA) — needs hosting over https, which needs Eddie's OK

The `dist/` folder is a ready-to-host web app: `index.html`, `manifest.webmanifest`, `sw.js`
(offline cache), and `icons/`.

**Hosting it anywhere public is publishing. Do not do it without Eddie's explicit OK for that build.**

Once Eddie approves a host and it is served over **https**:

1. On the iPhone, open the https address in **Safari** (not Chrome, not an in-app browser).
2. Tap the **Share** button (square with an arrow).
3. Scroll and tap **Add to Home Screen**. The name shows as **XOE**. Tap **Add**.
4. Open XOE from the Home Screen. It runs full screen, without Safari's bars, and works offline
   after the first open (prices and Grok Bot still need the internet).

Notes:
- Safari only installs over https (or `http://localhost` on a computer). A plain `http://` address on
  your Wi-Fi will play in Safari, but the offline cache will not turn on.
- Android: open the https address in Chrome → menu (⋮) → **Install app** / **Add to Home screen**.
- To update: host the new `dist/`; the app picks up the new version the next time it opens.

## 3. Native app shell (Capacitor) — scaffolding only

The repo now has a Capacitor shell around the same `dist/` files:

- `capacitor.config.ts` — app id `local.xoe.unknownorbitalengine` (placeholder, change before any
  store use), name "XOE: Unknown Orbital Engine", `webDir: "dist"`.
- `ios/` — Xcode project (Swift Package Manager, no CocoaPods needed), generated by `npx cap add ios`.
- `android/` — Android Studio / Gradle project, generated by `npx cap add android`.
- Packages: `@capacitor/core`, `@capacitor/cli`, `@capacitor/ios`, `@capacitor/android` 8.6, all as
  devDependencies (a plain `npm install` installs them). The game code does not import any Capacitor
  plugin, so the web build and its "runtime = react/preact only" offline check are unchanged.

These were generated on a Linux box. **No app was built, signed, or uploaded, and no Apple or Google
account was touched.**

### Refresh the native projects after a new web build

```
bash scripts/build-v19.sh      # builds dist/ (game + PWA files)
npx cap sync                   # copies dist/ into ios/ and android/
```

### What a Mac needs to build the iPhone app

- A Mac with **Xcode** (current version from the Mac App Store) and Node.js 22 or newer.
- `npm install`, then `bash scripts/build-v19.sh`, then `npx cap sync ios`, then `npx cap open ios`.
- In Xcode: pick the **App** target → **Signing & Capabilities** → choose a Team.
  - To run on Eddie's own iPhone: a free Apple ID works (the app expires after 7 days).
  - For TestFlight / App Store: an **Apple Developer Program** membership ($99/year) and Eddie's
    explicit OK. That is publishing.
- Plug in the iPhone (or pick a Simulator) and press **Run**.

### What Android Studio needs to build the Android app

- **Android Studio** (any OS) with an Android SDK and a JDK 21 (bundled with Android Studio).
- `npm install`, `bash scripts/build-v19.sh`, `npx cap sync android`, `npx cap open android`.
- Press **Run** with a phone in developer mode (USB debugging) or an emulator. A debug build needs no account.
- A Play Store release needs a signing key, a Google Play developer account, and Eddie's explicit OK.

### Known gaps in the native shell (not fixed yet, on purpose)

- The service worker is for the web/PWA only. Inside the native app the files are already on the
  phone, so its registration simply fails quietly (it has a `.catch`).
- Live prices come from Coinbase's public API. Inside the app the page origin is
  `capacitor://localhost` (iOS) or `https://localhost` (Android). If Coinbase ever refuses that
  origin, the ticker falls back to its offline/sim labels, the same as with no internet. Not tested on a device.
- Voice uses the phone's Web Speech support inside the web view, which may differ from Safari.
- App icons/splash screens in `ios/` and `android/` are Capacitor defaults until real ones are chosen.

## How this was checked (local only)

- Real WebKit (Safari's engine) via Playwright, "iPhone 15" portrait (393×659) and landscape (734×343),
  over `http://127.0.0.1` (the `dist/` PWA, service worker on) and `file://` (the single HTML),
  for a first-time player and a returning player: `node review-webkit-iphone.mjs`
  (results in `review/webkit-iphone.json`, screenshots `review/webkit-iphone15-*.png`).
- Also `node review-iphone-boot.mjs` (WebKit + Chromium, storage on/off, JS off) and
  `node review-map-first.mjs` (Chromium + WebKit).
- This is an emulator, not Eddie's actual iPhone. A real-device check is still the final word.
